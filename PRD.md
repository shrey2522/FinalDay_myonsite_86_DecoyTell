# 86. DecoyTell — Bounded Deception-Surface Consistency Verification

**86. DecoyTell — Bounded Deception-Surface Consistency Verification**
**Problem Statement**
A deception asset is useful only if the observable properties available to an attacker remain consistent with comparable real assets. Open-ended guesses about what an attacker might notice are not reproducible, so the challenge uses a declared comparison surface: a finite set of observable attributes such as patch cadence, service banners, response timing bands, account-age metadata, and monitoring behavior. Design a system that compares simulated decoys with matched real assets across this declared surface, detects which observable differences exceed allowed tolerances, and either corrects the specific drift or marks the decoy unsafe to expose. The evaluation includes one harmless variation inside tolerance, one revealing drift, and one pair where two individually small differences combine into a uniquely identifying fingerprint. A convincing demonstration should output the exact attributes responsible for disclosure and verify after correction that the decoy no longer falls outside the declared comparison model.
